# AI Practical Repository

This repository contains Python implementations of various practicals for the **AI** course.


### Files and Folders:

- **Practical 1/**
  - Contains BFS and DFS implementations in separate Python files:
    - `bfs.py`: Implements Breadth-First Search algorithm.
    - `dfs.py`: Implements Depth-First Search algorithm.

- **pr2_A_star.py**  
  Contains implementation of the A* Search algorithm.

- **pr3_sel.py**  
  Code for selection-based operations (possibly Feature Selection or Selection Sort).

- **pr4_gr_color.py**  
  Graph coloring algorithm practical.

- **pr5_chatbot.py**  
  A simple chatbot implementation.

- **pr6_hosp_mgt.py**  
  Hospital management system simulation.
